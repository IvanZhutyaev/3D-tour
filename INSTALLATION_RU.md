# Инструкция по установке и запуску

Пошаговое руководство на русском языке для создания 3D-тура.

## Шаг 1: Установка зависимостей

Откройте терминал (PowerShell или CMD) в папке проекта и выполните:

```bash
npm install
```

Эта команда установит:
- Three.js - библиотеку для 3D-графики
- Vite - инструмент для разработки и сборки

## Шаг 2: Добавьте панорамные фотографии

### Создайте папки для изображений:

```bash
mkdir public
mkdir public\images
```

### Добавьте ваши панорамные фото в `public\images\`:
- panorama1.jpg
- panorama2.jpg
- panorama3.jpg

### Требования к панорамам:
- **Формат**: Equirectangular (сферическая панорама 360° x 180°)
- **Соотношение сторон**: 2:1
- **Разрешение**: рекомендуется 4096x2048 или выше
- **Форматы файлов**: JPG, PNG, WebP

## Шаг 3: Как создать панорамные фото

### С помощью смартфона:
- **Google Street View** (iOS/Android) - бесплатно
- **Panorama 360** (iOS/Android) - бесплатно
- **Cardboard Camera** (Android) - бесплатно

### С помощью зеркальной камеры:
1. Сделайте серию перекрывающихся фотографий по кругу
2. Склейте их в программе:
   - **Hugin** (бесплатная, open-source)
   - **PTGui** (профессиональная)
   - **Adobe Photoshop** (функция Photo Merge)

### 360° камеры:
- Ricoh Theta
- Insta360
- GoPro MAX

## Шаг 4: Настройка тура

Откройте файл `src\tourConfig.js` и настройте ваш тур:

```javascript
export const tourConfig = {
    scenes: [
        {
            name: 'Первая комната',           // Название сцены
            image: '/images/panorama1.jpg',   // Путь к панораме
            initialLon: 0,                    // Начальный угол обзора (горизонталь)
            initialLat: 0,                    // Начальный угол обзора (вертикаль)
            hotspots: [
                {
                    lon: 90,                  // Позиция хотспота (горизонталь)
                    lat: 0,                   // Позиция хотспота (вертикаль)
                    targetScene: 1,           // Номер целевой сцены
                    title: 'Перейти во вторую комнату'
                }
            ]
        },
        {
            name: 'Вторая комната',
            image: '/images/panorama2.jpg',
            initialLon: 180,
            initialLat: 0,
            hotspots: [
                {
                    lon: 0,
                    lat: 0,
                    targetScene: 0,
                    title: 'Назад в первую комнату'
                }
            ]
        }
    ]
};
```

### Система координат:

**Longitude (lon) - долгота (горизонталь):**
- 0° = прямо
- 90° = справа
- 180° = сзади
- -90° или 270° = слева

**Latitude (lat) - широта (вертикаль):**
- 90° = вверх
- 0° = на уровне глаз
- -90° = вниз

## Шаг 5: Проверка конфигурации

Проверьте правильность настройки:

```bash
npm run validate
```

Эта команда покажет ошибки и предупреждения в конфигурации.

## Шаг 6: Запуск проекта

### Вариант 1 - Через командную строку:
```bash
npm run dev
```

### Вариант 2 - Двойной клик на start.bat:
Просто дважды кликните на файл `start.bat` в проводнике Windows.

Проект автоматически откроется в браузере по адресу `http://localhost:3000`

## Управление туром

### На компьютере:
- **Перетаскивание мышью** - осмотреться
- **Колесико мыши** - приблизить/отдалить
- **Клик на хотспот** - перейти в другую сцену
- **Кнопка полного экрана** - развернуть на весь экран

### На мобильном:
- **Свайп** - осмотреться
- **Пинч** - приблизить/отдалить
- **Тап на хотспот** - перейти в другую сцену

## Сборка для размещения в интернете

Когда тур готов, соберите его для публикации:

```bash
npm run build
```

Готовые файлы появятся в папке `dist\`. Загрузите содержимое этой папки на любой хостинг:
- GitHub Pages
- Netlify
- Vercel
- Любой другой хостинг статических сайтов

## Тестовая демонстрация без установки

Если хотите быстро посмотреть, как это работает без установки зависимостей:

Откройте файл `demo-standalone.html` в браузере. Это упрощенная версия без сборки.

## Решение проблем

### Ошибка "Cannot find module 'three'"
Выполните: `npm install`

### Изображения не загружаются
- Проверьте пути в `tourConfig.js`
- Убедитесь, что изображения находятся в `public\images\`
- Проверьте консоль браузера (F12)

### Хотспоты не видны
- Проверьте координаты lon/lat
- Убедитесь, что targetScene указывает на существующую сцену
- Попробуйте повернуть камеру в разные стороны

### Медленная загрузка
- Сжимайте изображения перед использованием
- Используйте качество JPEG 70-80%
- Уменьшите разрешение панорам
