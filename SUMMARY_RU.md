# 📸 3D Panoramic Tour - Итоговая информация

## 🎉 Что создано

Полноценный проект на Three.js для создания интерактивных 3D-туров из панорамных фотографий.

```

├── 📄 main.js                 - Основной скрипт
├── 📄 style.css               - Стили интерфейса
├── 📄 package.json            - Зависимости проекта
├── 📄 vite.config.js          - Конфигурация сборки
│
├── 📁 src/                    - Исходный код
│   ├── PanoramaTour.js       - Движок тура (главный класс)
│   ├── tourConfig.js         - Конфигурация тура (редактировать здесь!)
│   ├── configValidator.js    - Проверка конфигурации

├── 🚀 start.bat              - Быстрый запуск для Windows

    └── CONTRIBUTING.md       - Руководство для разработчиков
```

## 🚀 Быстрый старт

### 1. Установите зависимости:
```bash
npm install
```

### 2. Создайте папку для панорам:
```bash
mkdir public
mkdir public\images
```

### 3. Добавьте панорамные фото в `public\images\`

### 4. Настройте тур в `src\tourConfig.js`

### 5. Запустите:

**Вариант A** - Двойной клик на `start.bat`

**Вариант B** - В командной строке:
```bash
npm run dev
```

Откроется браузер по адресу `http://localhost:3000`

## 📸 Требования к панорамам

- **Формат**: Equirectangular (сферическая панорама 360° x 180°)
- **Соотношение сторон**: 2:1 (например, 4096x2048)
- **Разрешение**: минимум 2048x1024, рекомендуется 4096x2048 или выше
- **Форматы файлов**: JPG, PNG, WebP
- **Оптимизация**: сжимайте изображения для быстрой загрузки

## 🛠️ Как создать панорамы

### 360° камера:
- Ricoh Theta
- Insta360 ONE
- GoPro MAX

## ⚙️ Конфигурация тура

Откройте `src\tourConfig.js` и настройте:

```javascript
export const tourConfig = {
    scenes: [
        {
            name: 'Название сцены',
            image: '/images/panorama1.jpg',
            initialLon: 0,    // Начальный угол (0-360°)
            initialLat: 0,    // Наклон камеры (-90 до 90°)
            hotspots: [
                {
                    lon: 90,          // Позиция хотспота
                    lat: 0,           // Высота хотспота
                    targetScene: 1,   // Куда ведет (индекс сцены)
                    title: 'Описание'
                }
            ]
        }
    ]
};
```

### Система координат хотспотов:

**lon (долгота, горизонталь):**
- 0° = прямо
- 90° = справа
- 180° = сзади
- 270° = слева

**lat (широта, вертикаль):**
- 0° = на уровне глаз
- 45° = вверху
- -45° = внизу

## 🐛 Решение проблем

### Ошибка при установке
```bash
# Очистите кеш и переустановите
npm cache clean --force
npm install
```

### Панорамы не загружаются
1. Проверьте пути в `src\tourConfig.js`
2. Убедитесь, что файлы в `public\images\`
3. Откройте консоль браузера (F12) для ошибок

### Хотспоты не видны
1. Проверьте координаты lon/lat
2. Убедитесь, что targetScene существует
3. Попробуйте разные углы обзора

### Медленная работа
1. Сжимайте изображения (качество JPEG 70-80%)
2. Уменьшите разрешение панорам
3. Используйте WebP формат
